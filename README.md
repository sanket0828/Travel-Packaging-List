# 🧳 Travel Packer

Travel Packer is a simple React application that helps users create and manage a packing list for trips. Users can add items with quantities, sort the list, and reset everything once packing is complete.

This project was built to strengthen core React concepts like state management, component composition, and event handling.

---

## ✨ Features
- Add items with quantity
- Sort packing list by input order
- Clear the entire list with one click
- Minimal, travel-themed UI
- Fast and distraction-free user experience

---

## 🛠 Tech Stack
- React
- JavaScript (ES6+)
- CSS

---

## 🧠 What I Learned
- Managing state with `useState`
- Passing data via props
- Handling user input and form submissions
- Conditional rendering in React
- Structuring components for readability and reusability

## 📦 Getting Started

### Prerequisites
- Node.js
- npm

---

### Installation

Clone the repository:
```bash
git clone https://github.com/your-username/travel-packer.git
```

Navigate to the project directory
```bash
cd travel-packer
```

Install dependencies
```bash
npm install
```

Start the development server
```bash
npm start
```

Open the app in your browser
```bash
http://localhost:3000
```
